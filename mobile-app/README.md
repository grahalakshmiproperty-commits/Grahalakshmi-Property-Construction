# Grahalakshmi Property - React Native Android App

## Overview
Android mobile app for Grahalakshmi Property & Construction platform built with React Native.

## Features
- Property listing with filters
- User authentication
- Favorites management
- Admin panel for property management
- User profile management
- Real-time data sync with Supabase

## Quick Start
```bash
cd mobile-app
npm install
cp .env.example .env
npm run android
```

See SETUP.md for detailed instructions.
